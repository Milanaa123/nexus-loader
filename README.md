# Nexus Loader 1.6

Server-side Nexus Mods API bridge for the Stardew Valley Russian mod assembly.

- `NEXUS_API_KEY` is configured only in Vercel and must never be committed.
- Batch requests are limited to 20 Nexus mod IDs.
- A mod is not marked Russian-ready until Russian language support or a compatible translation has been verified.
- Download links are requested through the official Nexus API and remain subject to Nexus account/API download rules.
